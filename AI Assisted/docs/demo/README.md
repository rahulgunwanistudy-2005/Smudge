# Recorded demonstration

Canonical MP4: `../../app/static/demo/smudge-demo.mp4` (1920×1080,approximately135seconds,H.264/AAC, burned-in captions). `captions.srt` is the matching transcript. The app hosts a watch page at `/demo/`; video is excluded from offline prefetch.

The recording shows actual browser analysis, treatment, exact exported-JPEG checking, an offline reload and full processing run, and measured synthetic lab results. It uses generated textures, no person's fingerprints. Narration is generated by the local macOS system voice; it does not impersonate a person. Reproduce with `scripts/record-demo.py` on macOS with Playwright and ffmpeg installed.

The recording uses the final compressed asset server. It does not demonstrate a real phone, human protection or Share Target installation.

The privacy-proof segment uses an explicitly labelled still of the live deployed site, inspected online, so the actual response headers can be read. The rest is the real browser recording, including offline analysis and export. This edit does not replace matcher values. Exact media dimensions, duration and SHA256 are in media-verification.json.
