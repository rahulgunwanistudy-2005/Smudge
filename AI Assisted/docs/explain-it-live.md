# Explain Smudge live

1. **No cloud photo backend.** Static assets come from the host; all image computation runs in the browser worker. A server that received photos would contradict the privacy goal.
2. **Find a region.** MediaPipe suggests fingertips from DIP→TIP landmarks. Suggestions are axis-aligned conservative boxes, not complete oriented-patch rectification. The palm sign is uncertain and never used to declare a tip safe. Users review and adjust boxes. Document candidates use directional gradient energy, not a full multi-Gabor classifier.
3. **Normalize.** The core works on luminance, caps the working region at 512 pixels and computes tiled contrast enhancement, 16px gradient tensors, projected autocorrelation periods and oriented Gabor response. It also retains raw and CLAHE paths because Gabor can discard useful features. DPI defaults to 500; contactless physical-scale estimation is not calibrated.
4. **Extract.** NIST mindtct processes both polarities for raw/CLAHE/Gabor candidates. Choose the candidate with most reliable points. It returns ridge endings/bifurcations and reliability. NFIQ-style grade = clamp(5 − floor(HQ/8), 1, 5), not NFIQ neural-network output.
5. **Match.** NIST Bozorth3 compares distance/angle relationships between minutiae sets. The glue retains the best 150 points and converts to NIST coordinates. No reference means no displayed biometric match score. A synthetic baseline compares an image with itself; say that aloud.
6. **Suppress.** Overlapping 32px blocks use sine windows (their squared overlap is Hann). A 2D FFT attenuates a soft ridge-frequency band with orientation weighting. Inverse FFT and overlap-add reconstruct luminance. At high strength, a low-pass fallback removes surviving detail. Low-amplitude seeded noise prevents perfectly flat pixels; it is not demonstrated skin-texture synthesis.
7. **Close the loop.** Try strengths .4/.7/1; re-extract and test plain/sharpened/upscaled/JPEG variants. Require every score < 40 and every high-quality count < 6. A passed baseline is required for a diagnostic pass. Cap failures are shown.
8. **Exact export.** Compose luminance differences into RGB (clipping at gamut edges may alter chroma). Feather boundaries preserve zero-mask pixels before encoding. Apply any reviewed identifier masks. Encode JPEG quality .95, decode it, and re-run analysis on the exact exported pixels. Compute Gaussian-window SSIM (every other centre on large images) and full-image luminance PSNR against original. Original EXIF/GPS is not copied.
9. **Evidence.** Fifty native/WASM parity fixtures agree exactly. Twelve synthetic textures also have independent SourceAFIS checks. Neither is a human-protection study. Forty is provisional, not a measured FMR; learned SR and real-device budgets remain open.
10. **Privacy proof.** Show actual headers and observed external requests, then reload offline and run the complete flow. Do not claim a resource counter alone proves no exfiltration. Share Target has a one-time local handoff cache; ordinary uploads stay in memory.
